    Keys

    Keys, top row: C (clear/back), BOL (tap = programmed bolus, hold = manual bolus), ON/OFF (hold 3 s). Bottom row: OK, violet chevrons (auto-program), Start/Stop. Far right: door. Hold ▶ while infusing for macro mode.

    Desktop keyboard: arrows, Enter = OK, Esc/Backspace = C, Space or S = Start/Stop, X = door, M = auto-program, hold B = bolus, hold P = ON/OFF.

    About

    Unofficial practice simulator for learning pump programming sequences. Drug names, concentrations and limits are illustrative only and are not clinical reference.
